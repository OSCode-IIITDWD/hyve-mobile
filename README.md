# Hyve

Hyve is a unified campus mobile application designed to simplify logistics, access services, organize schedules, and foster community interaction.

## Features

* **Unified Campus Logistics**: Access campus services and administrative logistics friction-free.
* **Announcements & Community**: Stay updated with campus news, events, and community announcements.
* **Schedules & Planners**: Track timetables, events, and daily planners in one central place.

## Getting Started

To run the application locally:

1. Ensure you have the Flutter SDK installed (targeting SDK `^3.11.3`).
2. Run the following commands:
   ```bash
   flutter pub get
   flutter run
   ```
